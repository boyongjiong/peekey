> 视觉参考用户提供的截图：浅色底、大圆角渐变卡片、超大验证码数字、右上角倒计时环。

| Token | 值 |

| 窗口尺寸 | 默认 360 × 520，最小 320 × 360，可调整 |

| 卡片间距 | 14pt |

**v2 评审结论与改动**

| 问题 | 改动 |
| --- | --- |
| 设置是低频操作，却常驻并与搜索、＋ 抢视觉 | ⚙︎ 移入标题栏，仅鼠标悬停窗口时淡入（占位不变，无布局跳动）；同时保留 ⌘, 和菜单栏右键入口 |
| 标题栏一整行空置，搜索行再占一行 | ＋ / ⚙︎ 用 `NSTitlebarAccessoryViewController` 放进标题栏，搜索独占整行 |
| 空状态仍显示搜索框 | 无账户时隐藏搜索 |
| `windowBackgroundColor` 偏灰，白底阴影搜索框显得像网页 | 背景改为 `#F7F8FA` / 深色 `#1E1E20`；搜索框改为 5.5% 填充、无阴影 |
| 白字在浅色卡片上对比度不足（金色仅 1.7:1） | 重做 10 套配色，浅端 ≥ 3:1（大号粗体标准），深端 ≥ 4.7:1 |
| 空状态两个同权重按钮、拖拽和快捷键能力不可见 | 单一主按钮 + 文字链接次要入口；整块区域即虚线拖放区；底部用键帽样式提示唤醒快捷键 |
| 无障碍 | 卡片合并为单个可访问元素（含验证码朗读）；图标按钮有标签；尊重「减少动态效果」；可点击元素显示手形光标 |

**卡片状态**

- **Hover**：卡片上浮 2pt（减少动态效果时不上浮），阴影加深，右下出现「点击复制」
- **键盘选中**（↑/↓）：卡片内描 2pt 白边
- **已复制**：半透明遮罩 + `✓ 已复制`，1.2s 后消失
- **无搜索结果**：「没有匹配“xxx”的账户 / 按 Esc 清除搜索」

## 9. App 图标 — 方案 C「Code Cards」

- 浅色圆角方块底（`#FFFFFF → #DCE2EC` 渐变 + 10% 深蓝描边），保证在浅色 Dock 上有边界
- 前景：后方紫色卡片（+8°）+ 前方蓝色卡片（−4°），配色与 App 卡片一致（`#8E6BF0→#6440D4`、`#3D8AF0→#2459D0`）
- 前卡内容：3+3 白色验证码条、发行方占位条、右上倒计时环 —— 直接映射主界面
- **16 / 32px 使用简化版**：单张正放大卡片 + 加粗码条 + 倒计时环，去掉后卡与细节
- 生成：`scripts/make-icon.swift` 直接输出完整 `.iconset`（阴影参数按尺寸缩放，避免小图出现底色污染）
- 备选方案 A/B/D/E 的探索记录见设计评审（锁孔透光、瞄眼、倒计时锁孔、字母钥匙）
