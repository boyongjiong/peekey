# 03 · 设计稿 — Peekey 瞄码

> 视觉参考用户提供的截图：浅色底、大圆角渐变卡片、超大验证码数字、右上角倒计时环。

## 1. 设计 Token

| Token | 值 |
|---|---|
| 窗口尺寸 | 默认 360 × 520，最小 320 × 360，可调整 |
| 窗口背景 | `windowBackgroundColor`（自动适配深色） |
| 卡片圆角 | 20pt（continuous） |
| 卡片内边距 | 16pt 水平 / 14pt 垂直 |
| 卡片间距 | 14pt |
| 卡片阴影 | 卡片主色 35% 透明度，radius 12，y 6 |
| Issuer 字体 | 15pt Semibold，白色 |
| 账户名字体 | 13pt Regular，白色 85% |
| 验证码字体 | 34pt Bold Rounded，等宽数字，白色；6 位码以 3+3 分组显示（`949 761`），复制时不含空格 |
| 倒计时环 | 18pt 直径，线宽 3，白色；剩余 ≤5s 变为白底红环并轻微闪烁 |

## 2. 主窗口

```
┌──────────────────────────────────────┐
│ ● ● ●                                │  ← 透明标题栏
│  ┌──────────────────────────┐ ┌──┐   │
│  │ 🔍 搜索                   │ │＋│ ⚙︎ │  ← 搜索框 + 添加（菜单）+ 设置
│  └──────────────────────────┘ └──┘   │
│  ╭────────────────────────────────╮  │
│  │ AdvanGuard - stg-acmp…      ◔  │  │  ← Issuer + 倒计时环
│  │ yongjiong.bo@advancegroup…     │  │  ← 账户名
│  │ 949 761                        │  │  ← 验证码
│  ╰────────────────────────────────╯  │
│  ╭────────────────────────────────╮  │
│  │ Sumsub - cockpit.sumsub…    ◔  │  │
│  │ pickleopen@lawling.cn          │  │
│  │ 019 634                        │  │
│  ╰────────────────────────────────╯  │
│                                      │
└──────────────────────────────────────┘
```

**状态**
- **Hover**：卡片上浮 2pt，阴影加深，右下出现「点击复制」提示
- **键盘选中**（↑/↓）：卡片外加 2pt 白色 + 主色描边
- **已复制**：卡片上覆盖半透明层，中间出现 `✓ 已复制`，1.2s 后消失
- **空状态**：居中插画（钥匙 SF Symbol `key.viewfinder`）+「还没有账户」+ 按钮「扫描屏幕二维码」「手动添加」
- **无搜索结果**：「没有匹配“xxx”的账户」

## 6. 设置窗口

```
┌───────────────────────────────────────────┐
│ 通用                                       │
│                                           │
│ 显示位置    ◉ 菜单栏                       │
│            ○ Dock                         │

│            ○ 都不显示（仅快捷键唤醒）        │

│ 版本 1.0.0                                 │
└───────────────────────────────────────────┘
```

- 选择「都不显示」时若快捷键为空 → 单选回滚，并在下方红字提示「请先设置唤醒快捷键」
- 快捷键录制：点击框 → 显示「按下快捷键…」→ 需要至少一个修饰键（⌘/⌥/⌃）

## 7. 菜单栏

- 图标：SF Symbol `lock.shield`（模板图像，自动适配深浅色）
- **左键**：在图标下方显示 / 隐藏主窗口
- **右键**：菜单「打开 Peekey ⌥⌘2 / 扫描屏幕二维码 / 设置… / 退出」

## 8. 主窗口定位

| 唤醒方式 | 位置 |
|---|---|
| 菜单栏图标 | 窗口顶部居中对齐图标，距菜单栏 6pt |
| 快捷键 / Dock | 上次关闭位置；首次为鼠标所在屏幕中央 |
