# 02 · PRD — Peekey 瞄码

## 1. 背景与目标

开发者和运维每天要输入很多次 2FA 验证码（云控制台、内部系统、SaaS 后台）。拿出手机解锁再找 App 的路径很长。Peekey 是一个 macOS 原生的 TOTP 验证器，目标是：

> **任何时候，一个快捷键 → 看到验证码 → 点击复制 → 窗口自动消失，全程不超过 2 秒。**

同时让用户自己决定 App 的「存在感」：菜单栏、Dock、两者都有，或者完全隐身、只用快捷键唤醒。

## 2. 目标用户

- 每天多次输入 2FA 的工程师、运维、产品、运营
- 对桌面整洁有要求、不想多一个 Dock 图标或菜单栏图标的用户

## 3. 平台

- macOS 14 Sonoma 及以上
- Universal Binary：Apple Silicon（arm64）+ Intel（x86_64）

## 4. 功能需求

### P0（MVP）

| # | 功能 | 描述 | 验收标准 |
| --- | --- | --- | --- |
| F1 | 账户列表 | 卡片列表展示所有 2FA 账户：发行方（Issuer）、账户名、当前验证码、剩余时间环 | 验证码按周期（默认 30s）自动刷新；倒计时 ≤5s 时环变红提示 |
| F2 | 点击复制 | 点击卡片复制当前验证码 | 出现「已复制」提示；如开启「复制后隐藏」，窗口自动隐藏 |
| F3 | 搜索 | 顶部搜索框按 Issuer / 账户名过滤 | 实时过滤，窗口唤醒后可直接打字搜索 |
| F4 | 扫码添加：屏幕 | 框选屏幕上的二维码（网页上的 2FA 二维码）识别并添加 | 支持 `otpauth://totp/...`；识别失败给出提示 |
| F5 | 扫码添加：图片 | 从图片文件选择 / 拖拽图片到窗口 / 剪贴板粘贴图片 | 同上 |
| F6 | 扫码添加：摄像头 | 用 Mac 摄像头扫描手机上的二维码 | 首次使用请求摄像头权限 |
| F7 | 手动添加 | 输入 Issuer、账户名、Secret（Base32），可选高级参数（算法 / 位数 / 周期） | Secret 校验非法时给出提示 |
| F8 | 链接添加 | 粘贴 `otpauth://` 链接添加 | — |
| F9 | 编辑 / 删除 | 右键卡片：编辑名称、更换颜色、复制 Secret 链接、删除（需二次确认） | — |
| F10 | 安全存储 | Secret 只存在 macOS 钥匙串（Keychain），不明文落盘 | 配置文件中不含 secret |
| F11 | **显示模式** | 四种模式可切换：①仅菜单栏 ②仅 Dock ③菜单栏 + Dock ④都不显示 | 切换立即生效，无需重启 |
| F12 | **全局快捷键** | 一键显示 / 隐藏主窗口（默认 `⌥⌘2`，可自定义） | 任意 App 在前台时都可用；再按一次隐藏 |
| F13 | 隐身模式兜底 | 选择「都不显示」时必须已设置快捷键；再次从 Finder / Spotlight 打开 App 也会唤醒窗口 | 防止用户找不回 App |

### P1

| # | 功能 | 描述 |
| --- | --- | --- |
| F14 | 批量导入 | 支持 Google Authenticator 导出的 `otpauth-migration://` 二维码 |
| F15 | 失焦自动隐藏 | 窗口失去焦点时自动隐藏（可关） |
| F16 | 窗口置顶 | 主窗口浮于其他窗口之上（可关） |
| F17 | 剪贴板自动清除 | 复制后 N 秒自动清除剪贴板中的验证码（若剪贴板未被其他内容覆盖） |

| F20 | 多语言 | 界面默认英文，设置中可切换「简体中文」，切换即时生效、无需重启（系统权限弹窗跟随系统语言） |
| F19 | 键盘操作 | `↑/↓` 选择，`↩` 复制，`Esc` 隐藏，`⌘N` 添加，`⌘,` 设置 |

## 5. 关键交互流程

### 5.1 日常取码

```
任意 App 中按 ⌥⌘2 → Peekey 窗口出现在屏幕中央（或菜单栏图标下方）
→ 直接输入关键字过滤 → ↩ 或点击复制 → 窗口自动隐藏 → ⌘V 粘贴
```

### 5.2 扫码添加（网页二维码）

```
点击 + → 「扫描屏幕二维码」→ 窗口暂时隐藏，出现系统框选光标
→ 框选二维码 → 识别成功 → 弹出确认表单（可改名）→ 保存 → 卡片出现在列表
```

### 5.3 切换到隐身模式

```
设置 → 显示位置：「都不显示」
→ 若未设置快捷键：阻止并提示先设置快捷键
→ 已设置：Dock 和菜单栏图标消失，提示「按 ⌥⌘2 唤醒 Peekey」
```

## 6. 非功能需求

- **安全**：Secret 仅存 Keychain；不联网、无统计、无遥测
- **性能**：唤醒到可见 < 100ms；常驻内存 < 50MB；空闲 CPU ≈ 0
- **体积**：安装包 < 10MB
- **可访问性**：支持系统深色模式；验证码使用等宽数字字体

## 7. 不做什么

- 不做云同步服务器
- 不做短信 / 邮件验证码
- 不做密码管理器
