# 01 · 应用命名

## 结论

| 项 | 值 |
|---|---|
| 英文名 | **Peekey** |
| 中文名 | **瞄码** |
| Bundle ID | `app.peekey.mac` |
| Slogan | 一键唤醒，瞄一眼验证码。 / *Peek at your keys.* |

## 命名思路

- **Peek + Key**：产品的核心场景是「按下快捷键 → 瞄一眼 6 位码 → 点击复制 → 自动消失」，"peek" 精准描述这种轻量、即用即走的交互；"key" 对应 2FA 密钥。
- 读音简单（/ˈpiːkiː/），两音节，适合作为菜单栏工具名。
- 中文「瞄码」与英文同义，口语化、好记。

## 备选

| 名称 | 说明 | 未选原因 |
|---|---|---|
| Blink | 一眨眼就拿到码 | 与知名 SSH 客户端重名 |
| TokenBar | 菜单栏 Token | 产品不只在菜单栏，限制定位 |
| Summon | 召唤 | 与 2FA 关联弱 |
| OneTap Auth | 一键验证 | 偏描述性，品牌感弱 |
